# WHERE THE FUCK AM I

[karpitony/eft-where-am-i](https://github.com/karpitony/eft-where-am-i)를 기반으로 만든 포크입니다.

## 원본에서 변경한 부분

- 여러 퀘스트 동시 피닝과 선택하지 않은 퀘스트 마커 숨김
- 피닝한 퀘스트의 목표·필요조건 패널 및 한국어 번역
- 배틀패스 다큐먼트 스폰 오버레이, 층별 표시, 위치 사진 팝업
- 퀘스트 및 배틀패스 팝업 닫기 버튼과 투명도 조절
- 글자 크기, 아이콘 크기, 패널 너비 등 UI 조절 기능
- 플레이어·팀원 위치와 방향 표시, 호스트/클라이언트 방식의 스쿼드 기능
- 광고와 사용 불가능한 유료 기능 표시 제거
- Windows x64 포터블 배포 및 프로그램 내 자동 업데이트

## 멀티세션 접속 방식

- 호스트: TCP `16243` 포트포워딩 및 Windows 방화벽 허용 → 이름·비밀번호 입력 → `호스트 시작`
- 클라이언트: 호스트의 공인 IP, 포트 `16243`, 동일한 비밀번호 입력 → `호스트 참가`
- 같은 공유기에서는 공인 IP 대신 호스트 내부 IP 사용
- 위치와 방향은 스크린샷을 찍을 때 갱신됨
- 호스트 종료 시 전원 연결 해제
- 비밀번호는 12자 이상 권장
- 클라이언트 최대 8명

> [!CAUTION]
> **호스트 IP 및 포트를 참가자 외부에 노출하지 마십시오.**
